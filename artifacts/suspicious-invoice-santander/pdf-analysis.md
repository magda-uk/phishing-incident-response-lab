# PDF Analysis (Fake Invoice): “Actualización de seguridad de cuenta”
**Analysed file:** `Invoice Actualizacion de seguridad de cuenta.pdf`

## 📸 PDF Preview (Safe GitHub View)
![PDF preview](/artifacts/screenshots/pdf-preview-github.png)

## 🧩 Overview
This PDF is attached to a phishing email impersonating “SantanderEquipo, Inc.” and generated via inFakt.pl.  
The invoice is titled **“Actualización de seguridad de cuenta”**, matching the email subject and reinforcing the social engineering theme of “account security update”.

The document attempts to look like a legitimate Polish invoice while using obviously fake data.

## 🔍 Indicators of Fraud

1. **Nonsense data**  
   Seller, buyer, addresses, VAT codes and service names are random strings.

2. **Mismatch with email narrative**  
   Email claims to be a security update → PDF is a generic invoice.

3. **Social engineering via invoice theme**  
   The “paid invoice” is used to add legitimacy and urgency.

4. **Abuse of legitimate platform**  
   Attackers used inFakt.pl to generate a clean-looking invoice.

## 📝 Conclusion
This PDF is not a legitimate invoice but a supporting artefact in a phishing campaign.  
Its purpose is to add perceived legitimacy and confusion to the email, increasing the chance that victims click the malicious link.
